# Future farmer-operated equipment data: integration discovery and contributor rights

**Status:** research for a later, buyer-backed capability. No customer accounts, equipment connections, consent grants, data purchases, royalties or subscriptions have been created. **Original cross-domain commercial Work:** [561 Group Opportunity #31](https://github.com/561-group/561-group-opportunity-services-section/issues/31). **Supplier Work:** [Red Cup paid-data #11](https://github.com/red-cup-engineering/paid-data-endpoint-service/issues/11). **Near-term source research:** [AGRICULTURAL-DATA.md](AGRICULTURAL-DATA.md).

AgGateway's [ADAPT Standard](https://aggateway.org/Resources/ADAPT) is **data-only** and distinct from the older .NET [ADAPT Framework](https://github.com/AgGateway-ADAPT/ADAPT). It provides production data JSON Schemas/controlled vocabularies and supports GeoParquet/GeoTIFF/WKT. Check the actual schema version and validate the produced file. Do not mislabel worm bin observations as ISOXML field machine tasks. See also the [ADAPT Standard source and schema files](https://github.com/AgGateway-ADAPT/Standard).

## Evaluation order under near-zero operating capital

A small farm can already download/export some existing data, or manually supply a few observations; a consented **file import** is therefore the first equipment-path assay. Start with an isolated, operator-provided example stripped of personal/site-sensitive details where permitted. Identify the owner and any other rights-holders, exact original encoding, unit dictionary, observation period, source timezone, machine identity, field location resolution and transformations the farmer understands.

Only after an identified buyer wants a field-data feature should the second assay compare **provider-direct OAuth** (ongoing compliance/maintenance) against a **consolidation API** (monthly subscription and additional contract/rights risks). No unattended syncing, polling schedules, secret ingestion, or capital advance should precede a specific authorization and bounded use. A provider integration that helps a farmer with analysis can still be a valid service even when the farmer explicitly refuses data resale.

## Minimum truthful contributor offer

Rights and economics must be independent resources, not a general account setting:

- A genuine operator/custodian with verified authority over the selected source and each implicated field/site, plus any cooperative, Indigenous collective, employer, landlord or equipment-platform permission.
- Precisely selected observations/lot, time and space granularity, de-identification/aggregation policy, quality thresholds, permitted AI training vs inference, analysis, redistribution and sublicensing separately, named expected buyers/use purposes, retention/withdrawal and a real audit surface.
- The **source-acquisition permission**, **seller's transfer permission** and **specific buyer/merchant contract** remain different. If any missing/expired/contested, no sale. Permission to inspect a farm is not the purchase of a database right.
- An actual offer with gross buyer price, license period, original product/edition digest, original publisher/producer credit, reproducible source transformations, buyer acceptance and a **contracted** contributor payment rule. No guaranteed royalty, no token, no self-paid buyer.
- Following externally verified settlement, apply the agreed share *once* per independently settled use, less only disclosed allowed fees/costs; preserve tax/identity obligations outside the observation dataset. On revoked permission, block **new** transfers and issue downstream corrections; prior licensed deliveries have contractual/retention obligations to examine, not magical retroactive deletion.

A unit economics record should explicitly measure: `grossBuyerReceipt`, `actualFacilitatorCharge`, `sourceProviderCost`, `sourceValidationCost`, `computeStorageAndEgress`, `supportAndDisputeCost`, `agreedContributorPayout` and `resultingMargin`. **Unknown is not zero**. Optimize for useful recurring *buyer demand per consented source*, not maximum source bytes or speculative equipment connections.

## Agentic web interoperability without silo-building

The authoritative original Newswire release should expose an actual qualified Dataset/DataService (W3C DCAT 3 and PROV-O source chain), with a versioned machine-usable response, units, geometry/coverage and original license terms. Farm-field spatial data may use GeoParquet/OGC, imagery STAC/GeoTIFF, sensor data OGC SensorThings, or ADAPT Standard for agronomic operations **only when the original observation actually fits those profiles**. No novel opaque JSON jargon when a mature vocabulary exists. For private farm data, an agent may discover a **non-sensitive availability description**, not a precision field map or individual productivity before owner consent.

First measure whether a direct NASS/NOAA dataset/service saves the buyer substantial work; only then pursue the scarce and legally complex OEM channel. No contributor payment is proposed before an actual willing downstream buyer is independently evidenced.
