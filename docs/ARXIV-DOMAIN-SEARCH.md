## One source page: exact custody before any candidate

`./arxiv-oai-source` exports:

- `arxivOaiListUrl({set?,from?,resumptionToken?})` — OAI-PMH `ListRecords` with `metadataPrefix=arXiv`; continuation token must be the only selector. A caller's `from` is a **metadata modification watermark**, not article submission date. New manuscripts, updates, and withdrawn/deleted records have distinct predicates.
- `acquireArxivOaiPage({set?,from?,resumptionToken?,store?,root?,rateGate,fetchImpl?,parseXmlDocument?,observedAt?,maxBytes?})` — one bounded official HTTPS page, rejects redirects, non-XML/malformed XML and oversized bodies, keeps exact decoded HTTP response bytes and SHA-256 through the original immutable custody store **before parsing**, verifies readback, and returns only `not-approved` source candidates with precise `complete`/`resumptionToken`/metadata/date/rights coverage. Requires a supplied cross-machine `rateGate` that acquires and releases a shared exclusive lease with **at least 3000 ms spacing across OAI/RSS/search API requests**, including failure paths. That distributed gate must be furnished by the existing source-acquisition operator: a process-local sleep cannot satisfy publisher terms across fleet hosts. There is no automatic retry storm or user-controlled redirect target.
- `parseArxivOaiDocument(xmlDocument)` — pure projection of the existing ordered namespaced XML carrier, strict OAI/arXiv expanded-name qualification, stable original arXiv paper identity, metadata revision digest and last-modified datestamp, title/abstract/authors/categories, explicit missing/unknown version, and exact `deleted-from-oai` handling that **does not** pretend a deleted metadata record is a formal paper withdrawal.
- `advanceArxivWatch(previous,page)` — pure idempotent source-edition delta for an externally persisted index, refuses stale or contested same-datestamp revisions unless original source-response order is independently witnessed. Returns a proposed updated snapshot and continuation token; **does not commit a cursor or notify subscribers**. The original `scripts/refresh-arxiv-source-editions.mjs` composes this operator with existing content-addressed custody and `writeTextAtomically`: it commits one full bounded window only after every OAI page is witnessed, keeps the earlier state on partial failure, and retains one real original paper identity across replays. Its `data/records/newswire/arxiv/source.json` declaration selects the original math.CT family, and `latest.json` with digest-named original XML byte objects is installed by the source-owning GitHub Actions mainline job after native receiving. This is **source observation**, not an approved published Newswire or subscribed customer search.
- `arxivNewswireCandidates(page)` — maps verified metadata into source-backed *unapproved* scholarly records. A genuine Newsroom/Science acceptance is still necessary before original Newswire publication. The original Newswire query/provenance/publisher and original paid-data seller remain unchanged.

Parser limit: the existing XML reader currently bounds one input to **1 MiB** and structural limits; upstream OAI pages larger than that will be refused safely. This is a real limitation for broad harvesting, not evidence of complete coverage. Resolve the original XML reader's bounded large-page/streaming admission under its source owner before claiming a full arXiv index.

## Publisher policy (checked 2026-10-27)

- [Official arXiv OAI interface](https://info.arxiv.org/help/oa/index.html): `https://oaipmh.arxiv.org/oai`, `arXiv` for latest-version metadata and `arXivRaw` for richer version history. OAI `datestamp` is the metadata modification date, **not** submission or replacement date. Set scope and continuation are explicit; tokens expire daily. For completed initial synchronization, resume with `from` equal to the previously received server watermark and deduplicate repeated record identities. Treat unfinished harvest as partial.
- [Official arXiv API terms](https://info.arxiv.org/help/api/tou.html): descriptive metadata is CC0 and can support commercial search/notifications. The one-request/3-second, one-connection rule applies to **all Group-controlled machines combined**. PDF/TeX/e-print content and the site brand carry distinct rights; no universal commercial redistribution permission or endorsement. Link to original arxiv.org abstract pages.
- The `rights` fields are **source-policy pointers**, not an executed per-SKU admission of downstream sublicense/redistribution. Existing Market rights and editorial gates shall refuse unauthorized content and stale source terms before issuing an x402 challenge.
